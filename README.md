# Simple Interest Calculator

This repository contains a Bash script that calculates simple interest from values entered by the user.

Simple interest is calculated using:

**Simple Interest = Principal × Rate × Time / 100**

## Inputs

- **Principal:** The initial amount of money.
- **Rate of interest:** The annual interest rate as a percentage.
- **Time period:** The duration of the investment or loan in years.

## Usage

Run the calculator from a Bash-compatible terminal:

```bash
bash simple-interest.sh
```

Enter the principal, rate of interest, and time period when prompted. The script displays the calculated simple interest.
